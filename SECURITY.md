# Security Policy

## Reporting a vulnerability

We take security vulnerabilities seriously. Please do not report vulnerabilities
through a public GitHub issue.

Report them using one of these private channels:

- [InterWay responsible vulnerability reporting](https://www.interway.sk/sluzby-riesenia/zodpovedne-oznamovanie-zranitelnosti/)
- Email `zranitelnosti@interway.sk`; the published PGP key fingerprint is
  `38F5 F695 642A 7A1C 73AF 6C7E 90DC 0AF8 975E 50AD`
- [GitHub private vulnerability reporting](https://github.com/webjetcms/webjet-ai/security/advisories/new)

Include the affected version, relevant source locations, reproduction steps,
impact, and a proof of concept when possible. We will acknowledge the report,
investigate it, and coordinate disclosure after a fix is available.

## Supported versions

Security fixes are provided for the latest stable release. Consumers should use
the newest available patch version.
